# 财报分析 AgentScope 2.x Demo

本项目仅实现 `financial-report-analysis` 子智能体。Agent 编排使用 AgentScope 2.0.5（2.x API），数据库使用 Docker MySQL，数据由 Mock 信贷系统接口生成。

请阅读 `financial-report-analysis/agentscope_demo/README.md` 获取完整安装、初始化数据库和运行说明。

重要：请使用 Python 3.11/3.12 独立虚拟环境，不要在已有 Anaconda base 环境中直接覆盖安装。当前 Mock 数据均为虚构数据。
